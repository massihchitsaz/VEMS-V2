VTC ONE CONNECTED FOUNDATION - PACKAGE 1

Apply this package only to a backup/copy of the project, for example VEMS_DEV.

Steps:
1. Extract this ZIP.
2. Copy all extracted files into the root of VEMS_DEV.
3. Allow Windows to merge folders and replace duplicate files.
4. Open VEMS_DEV in VS Code.
5. Run: npm.cmd install
6. Run: npm.cmd run build
7. If build succeeds, run: npm.cmd run dev
